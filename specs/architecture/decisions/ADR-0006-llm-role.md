# ADR-0006: Роль LLM — опциональная интерпретация, не анализ

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

В системе предусмотрен AI-assisted анализ (FR-016). Нужно определить границы использования LLM, чтобы не подменять детерминированный анализ.

## Решение

LLM (DeepSeek 4 Pro через адаптер) используется только для интерпретации результатов, объяснения отклонений и формирования рекомендаций. Построение графа, проверка ограничений и Change Impact Analysis выполняются детерминированно. Результаты LLM помечаются как предложения и требуют подтверждения разработчиком.

## Обоснование

- Детерминированность и воспроизводимость результатов анализа.
- Снижение риска галлюцинаций и ложноположительных выводов.
- Приватность: анализ возможен без отправки кода во внешние сервисы.

## Последствия

- Плюсы: надёжность, контролируемость.
- Минусы: ограниченная «умная» автоматизация (приемлемо для MVP).
