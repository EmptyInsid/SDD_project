# ADR-0001: Язык backend — Go

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

Необходимо выбрать язык для backend-разработки ACIA. Система требует статического анализа Go-кода, построения графа зависимостей и работы с Git. Проект реализуется одним разработчиком.

## Решение

Использовать Go (Golang).

## Обоснование

- Нативные средства разбора Go-кода: `go/parser`, `go/ast`, `go/types` (задача FR-005).
- Статическая типизация и простота для одного разработчика.
- Библиотеки для работы с Git (`go-git`) и графами (`gonum/graph`).

## Последствия

- Плюсы: точный анализ Go-кода, производительность, воспроизводимые бинарники.
- Минусы: ограниченная поддержка других языков без дополнительных адаптеров.
- Требование: адаптеры анализа по языкам должны быть заменяемыми (порт `SourceReader`).
