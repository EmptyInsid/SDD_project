# ADR-0003: PostgreSQL как основная СУБД

- **Статус:** принято
- **Дата:** 2026-11-04

## Контекст

Требуется хранение спецификаций, графа зависимостей и результатов анализа.

## Решение

Основная СУБД — PostgreSQL. Для офлайн MVP допустимо файловое хранилище/SQLite за тем же портом `GraphStore`/`SpecStore`.

## Обоснование

- Надёжность, целостность и транзакционность.
- Полная поддержка стандартов SQL (в отличие от MySQL), конкурентная запись (в отличие от SQLite).
- Соответствует предпочтениям задания.

## Последствия

- Плюсы: целостность данных, возможность аналитических запросов.
- Минусы: требуется развёртывание БД; для простоты MVP — резервный офлайн-режим.
