# UML-диаграммы ACIA

Диаграммы в формате PlantUML. Эквивалентные Mermaid-диаграммы приведены в `docs/project-report.md` (Раздел 5).

| Файл | Диаграмма |
|---|---|
| `use-case.puml` | Use Case Diagram |
| `component.puml` | Component Diagram |
| `sequence-analysis.puml` | Sequence Diagram (сценарий анализа PR) |
| `activity-change-impact.puml` | Activity Diagram (Change Impact Analysis) |
| `class.puml` | Class Diagram (доменные сущности) |

Рендеринг PlantUML: https://plantuml.com/ (или локально через plantuml.jar).
